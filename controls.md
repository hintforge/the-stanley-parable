Standard PC first-person controls. Jumping is bound but **disabled in normal play** -- spamming it triggers the "You can't jump" achievement.

## Default keybindings

| Action | Key | Notes |
|---|---|---|
| Interact / Use | **E** AND **Left Mouse Click** | both default; wiki references "the action button (E or primary click)" |
| Movement | **W / A / S / D** | arrow keys not bound by default |
| Look / camera | **Mouse** | |
| Crouch | **Ctrl** | |
| Jump | **Spacebar** | bound but disabled; functional only in the Jump Circle (36 jumps). Spamming triggers **You can't jump** |
| Pause / Menu | **Esc** | standard default; not directly quoted in sources -- medium confidence |
| Auto-walk | toggle (added in Patch 1.07) | previously hold-to-use; no documented default key -- **unconfirmed** |

_Esc and the auto-walk default key are standard-default inferences, not directly quoted._

## Remapping & accessibility

- **Remapping:** Options → Keyboard/Mouse → Edit Keybindings. Crows Crows Crows: "Keyboard and gamepad controls are fully customisable."
- **Simplified Controls** toggle: on gamepad makes all face buttons interact; on PC it removes the jump input and makes interact double as interact+action.
- **Mouse-only play** (look + walk forward) is supported -- "through most of the game with one hand."

## Achievement bindings
- **You can't jump** -- press Space/jump several times where not interacting. See `achievements.md`.
- **Settings World Champion** is settings-driven, not controls-driven -- see `settings.md`.
