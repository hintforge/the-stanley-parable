# Paths -- Index

**status:** research-integrated
**last_reconciled:** 2026-06-02

Index of branching decision paths in The Stanley Parable: Ultra Deluxe. Documents the decision tree at each branch point and which choices lead to which endings.

## Files in this folder

- `decision_tree.md` -- structural backbone: Points of Divergence, named spaces, reset behavior, cross-playthrough state.
- `narrator_compliant.md` -- left-door (obedient) routing.
- `narrator_defiant.md` -- right-door (disobedient) routing.
- `new_content.md` -- Ultra Deluxe progression-chain routing (New Content → Sequel → Epilogue).
- `speedrun.md` -- Freedom-Ending sub-4:22 route.
- `door_430.md` -- the Door 430 click-chain.

## Primary branch points

1. **The Two Doors Room** -- the canonical first major choice. Left door (follow Narrator) vs. right door (disobey). Roots the main branching tree.
2. **Boss's Office keypad** -- 2845 (Freedom) vs. back-out (Escape Pod) vs. 8888 ×2 (achievement).
3. **Mind Control Facility** -- OFF (Freedom) vs. ON (Countdown) vs. ESCAPE hall (Museum) vs. fall-to-bottom.
4. **New Content door** (Door 416, once unlocked) -- the Ultra Deluxe progression chain.

Full POD list: see `decision_tree.md`.

## How to use this index

- Ask "how do I get the [ending name] ending?" for a step-by-step path walkthrough.
- Ask "what happens if I [action]?" to explore branch consequences.
- Ask "what's the fastest route to an ending?" → `speedrun.md`.
